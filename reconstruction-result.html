THE UNSEEN · RECONSTRUCTION FEASIBILITY TEST

A cleaner character can be recovered

This is an estimate reconstructed from the 81 public 640px hologram views. Neither clean source image was read by the reconstruction script.

What this means

Saving normally still produces a hologram snapshot. However, someone analysing all supplied views can recover this rough, largely foil-free character. The current design therefore does not meet the stronger requirement that visitors can only obtain the hologram appearance.

This is not the original full-colour artwork. Fine shading, original colours and some details are missing or wrong. It is nevertheless a meaningful reconstruction, not just a screenshot of one permitted view.

How the test worked

Using the known shader, view positions and simplified palette, the script rendered nine grey tones and one gold tone. For each pixel, it chose the tone whose simulated holograms best matched all 81 compressed public views. It ignored the unknown surface slopes. This was a white-box test with known rendering settings; no AI image generator or private original was used as reconstruction input.

Decision

The approved visual prototype is unchanged. Treat this delivery method as failing the strong hologram-only recovery boundary. Keeping clean files private remains useful, but is not sufficient to prevent this reconstruction. Before owner-access work, decide whether a rough reconstruction is acceptable or whether the public hologram must disclose less character information.
